# Third-party components

L-Note connects established open-source components instead of reimplementing their core responsibilities:

- Fuse.js 7.5.0 — fuzzy/token search, Apache-2.0.
- idb 8.0.3 — promise-based IndexedDB access, ISC.
- Zod 4.4.3 — runtime schema validation, MIT.
- Vite 8.1.5 — web development and production bundling, MIT.
- Vitest 4.1.10 — tests, MIT.

No third-party source code is copied into this repository; packages are installed from their published distributions.
